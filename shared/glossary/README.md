# Glossary

Cross-exam term definitions, written in plain English. One term (or a small cluster of closely related terms) per file, or a single running `terms.md` file — pick whichever stays easier to navigate as this grows.

## Contents

- **[terms.md](terms.md)** — the running A–Z glossary. Covers the terms that recur across CLF-C02 and SAA-C03, with the commonly confused pairs (durability vs. availability, Multi-AZ vs. read replicas, OLTP vs. OLAP, instance store vs. EBS) called out explicitly, since the confusion is usually what an exam question is actually testing.

Definitions are written for first contact with a term. The module that teaches a concept properly is always the better source for understanding it; this file exists for the moment you're mid-question and need a fast, honest answer.
