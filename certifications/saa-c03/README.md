# SAA-C03 — AWS Certified Solutions Architect – Associate

**Status: in progress.** This course follows AWS Academy Cloud Architecting's 16-module sequence, which builds directly on the CLF-C02 Cloud Foundations material and leads toward the AWS Certified Solutions Architect – Associate (SAA-C03) exam. Each module pairs a lecture (concept overview), a quiz (knowledge check, starting Module 2), and a learning activity or lab (hands-on practice) where AWS Academy's own course includes one.

Start at Module 1 and work down the table in order. Several challenge labs in this course are built around a running fictional case study — a café and bakery owned by Frank and Martha — that evolves its AWS architecture from a simple static website up through a secure, scalable, multi-Region, serverless-enhanced system across the course.

## How this builds on CLF-C02

If you completed [CLF-C02 Cloud Practitioner](../clf-c02-cloud-practitioner/), you've already met most of the services this course goes deeper on — Amazon S3, EC2, RDS, VPC, Elastic Load Balancing, EC2 Auto Scaling, and the AWS Well-Architected Framework all return here, but with real architectural depth and hands-on labs instead of conceptual overviews. This course assumes that foundation and builds on it directly, rather than re-teaching it from scratch.
