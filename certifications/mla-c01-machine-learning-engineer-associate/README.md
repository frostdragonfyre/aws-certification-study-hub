# MLA-C01 — AWS Certified Machine Learning Engineer – Associate

**Status: In progress.** Domain 1 (Data Preparation for Machine Learning) is complete — Modules 1-3. Domain 2 (ML Model Development) is underway — Module 4 of Modules 4-6.

This course follows a third angle on the same story world as SAP-C02 and SOA-C02: Diego Torres, Meridian Retail Group's Machine Learning Engineer, builds and operates the ML systems layered on top of what Sofía's team designed and Priya keeps running — a product-recommendation model for Meridian Loyalty, demand forecasting for Ridgeline Diner Co., and fraud detection for Café Sol's transactions. Where SAP-C02 asked "how should this be designed" and SOA-C02 asked "how do you operate this once it's live," MLA-C01 asks "how do you build, deploy, and run machine learning on top of it." Start at Module 1 and work down the table in order.

## How this relates to SAP-C02 and SOA-C02

If you're working through [SAP-C02 Solutions Architect – Professional](../sap-c02/) or [SOA-C02 SysOps Administrator – Associate](../soa-c02/) alongside this course, you'll recognize the same three systems — Meridian Loyalty, Café Sol, and Ridgeline Diner Co. SAP-C02 asks how to design, improve, and migrate a system; SOA-C02 asks how to keep it monitored, scaled, secured, and cost-efficient once it's live; MLA-C01 asks how to build, deploy, and operate the machine learning capabilities layered on top of both. The three courses can be taken independently, but the shared case study is deliberate: the same infrastructure and operational decisions from the other two tracks show up here as the platform Diego's ML systems run on.
