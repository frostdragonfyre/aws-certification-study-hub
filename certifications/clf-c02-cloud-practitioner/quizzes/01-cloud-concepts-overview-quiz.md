# Module 1 Review Quiz · Cloud Concepts

Allow about 20 minutes. Choose one answer unless the question says otherwise. For questions 11–15, write the detail in the scenario that supports your choice.

## Cloud characteristics and costs

1. An authorized developer creates a test server from a console without waiting for an infrastructure technician. Which cloud characteristic does that illustrate?
   - A. Resource pooling
   - B. On-demand self-service
   - C. Rapid elasticity
   - D. Measured service

2. A provider assigns isolated resources to many customers from a shared fleet. Which characteristic does that illustrate?
   - A. Broad network access
   - B. On-demand self-service
   - C. Measured service
   - D. Resource pooling

3. A dashboard tracks stored gigabytes and compute hours for a team's applications. Which characteristic does that illustrate?
   - A. Measured service
   - B. Broad network access
   - C. Resource pooling
   - D. Rapid elasticity

4. Juniper adds web capacity during registration and releases it when traffic returns to normal. Which capability is the team using?
   - A. Disaster recovery
   - B. Data residency
   - C. Elasticity
   - D. High availability

5. Juniper compares buying equipment before launch with paying monthly consumption charges. Which change is it evaluating?
   - A. Fixed-term software licensing to a capital purchase
   - B. Upfront capital expenditure to variable operating expense
   - C. Direct costs to shared internal overhead
   - D. Monthly operating expense to an upfront capital expense

## Deployment, service models, and location

6. A bookstore deploys its own catalog code to a service that manages the deployment environment. Which service model is the closest fit?
   - A. Software as a service
   - B. Infrastructure as a service
   - C. On-premises deployment
   - D. Platform as a service

7. Which two responsibilities should a team running a web app on Amazon EC2 assign to itself? **Choose two.**
   - A. Patching the guest operating system
   - B. Maintaining the physical network switches
   - C. Defining which application users may see reports
   - D. Replacing failed hardware in the data center

8. A customer wants to reduce latency for visitors downloading cacheable brochure images. Which location concept is most relevant to delivering those cached copies near users?
   - A. Availability Zone
   - B. Edge location
   - C. AWS account
   - D. On-premises subnet

9. A library rents access to a finished application for managing room bookings. Which task remains with the library?
   - A. Patching the vendor's booking application
   - B. Replacing the vendor's physical servers
   - C. Managing which library staff have access
   - D. Maintaining the application's hosting platform

10. Which two resources belong in a usage-based estimate for a public site? **Choose two.**
    - A. An unrelated vendor's equipment purchase
    - B. The site's retained storage
    - C. The customer's purchase price for the cloud provider's servers
    - D. The site's billable outbound data transfer

## Apply the concepts

11. Juniper moves its public registration site to AWS. The site must still exchange approved data with a records system that stays in the office. Which deployment model describes the combined system?
    - A. Hybrid
    - B. On-premises
    - C. Cloud-only
    - D. Platform as a service

12. A small publisher needs encrypted IP connectivity from its office network to AWS. It can use the public internet and has no requirement for a dedicated circuit. Which option fits the requirement?
    - A. AWS Storage Gateway
    - B. Amazon CloudFront
    - C. AWS Site-to-Site VPN
    - D. AWS Outposts

13. Juniper's web tier can handle registration traffic. The new requirement is for the site to keep serving requests if one Availability Zone fails. Which design change most directly addresses it?
    - A. Increase the instance size in the existing Availability Zone.
    - B. Cache the registration form's logo at edge locations.
    - C. Set a lower utilization threshold for scaling in the existing Availability Zone.
    - D. Serve traffic from healthy web instances in multiple Availability Zones.

14. Before migrating, Juniper needs to train registration staff and give the support team time to practice. Which AWS Cloud Adoption Framework perspective most directly addresses this need?
    - A. Platform
    - B. People
    - C. Governance
    - D. Operations

15. Juniper's team runs a recovery drill and measures how long it takes to restore registration after a simulated outage. Which Well-Architected pillar is the primary focus?
    - A. Cost optimization
    - B. Performance efficiency
    - C. Reliability
    - D. Sustainability
