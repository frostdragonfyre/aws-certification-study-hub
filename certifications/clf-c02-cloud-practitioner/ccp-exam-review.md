# CCP Exam Review — Foundations Complete

**Exam:** CLF-C02 — AWS Certified Cloud Practitioner
**Pairs with:** [Module 10: Auto Scaling and Monitoring](modules/10-auto-scaling-and-monitoring.md) · the final class of AWS Academy Cloud Foundations

## Why this matters

Ten modules, ten weeks, and every one of them was aimed at a single target: the AWS Certified Cloud Practitioner exam. Tonight isn't new content — it's the map that shows how everything you've learned since Module 1 lines up against the four domains the exam actually scores, plus the official AWS resources to use for the final stretch of studying before you sit the exam.

If you take one thing from tonight, take this: **you don't need to re-learn ten modules from scratch.** You need to know which domain each module feeds, and where your personal weak spots are inside that map.

## How the ten modules map to the four domains

CLF-C02 scores four domains. This is the same table from the course README, repeated here with the full module list, since it's the backbone of tonight's review.

| Exam Domain | Weight | Covered mainly in |
|---|---|---|
| Domain 1: Cloud Concepts | 24% | Module 1 (Cloud Concepts Overview), Module 9 (Cloud Architecture) |
| Domain 2: Security and Compliance | 30% | Module 4 (AWS Cloud Security) |
| Domain 3: Cloud Technology and Services | 34% | Module 3 (Global Infrastructure), Module 5 (Networking and Content Delivery), Module 6 (Compute), Module 7 (Storage), Module 8 (Databases), Module 10 (Auto Scaling and Monitoring) |
| Domain 4: Billing, Pricing, and Support | 12% | Module 2 (Cloud Economics and Billing) |

This mapping is approximate — several modules genuinely touch more than one domain (Module 9's Trusted Advisor content brushes against Security and Cost Optimization too, for example) — but it's the fastest way to triage your remaining study time. **Domain 3 is the single biggest chunk of the exam, and it's also the domain spread across the most modules** (six of ten), so if you only have time to review one thing this week, review Modules 3 and 5 through 8 and 10 together as one block.

### A practical way to use this table tonight

1. Take the Module 8, 9, and knowledge-check scores you already have and be honest about which modules felt shaky.
2. Cross-reference against the domain column above — a shaky Module 6 or 7 is a Domain 3 gap, worth more exam points than a shaky Module 2 (Domain 4 is only 12%).
3. Spend your remaining study time proportional to domain weight, not just to which module felt hardest — Domain 2 (Security, 30%) built entirely on Module 4 deserves real review time even if that class felt fine at the time.

## What changed if you've seen CLF-C01 material anywhere online

If you find older study material online referencing "CLF-C01," know that AWS retired that version and CLF-C02 is the current exam. The biggest differences: CLF-C02 added coverage of generative AI and modern AWS services, rebalanced domain weights, and refreshed several sample questions. Everything in this course was built against CLF-C02 — you don't need to cross-reference CLF-C01 material, and doing so risks studying content that's no longer tested.

## Key takeaways

- Foundations is complete — ten modules, all four exam domains covered at least once.
- Domain 3 (Cloud Technology and Services) is the largest slice of the exam at 34%, and it's built from the widest spread of modules — prioritize reviewing it if your time is limited.
- Use AWS's own resources first: the exam guide tells you exactly what's tested, and the Skill Builder exam prep plan is a free, structured path through review, practice questions, and a full practice exam.
- This exam validates foundational, high-level knowledge — you are not expected to have hands-on production experience, just a solid conceptual map of the AWS Cloud, which is exactly what these ten modules built.
