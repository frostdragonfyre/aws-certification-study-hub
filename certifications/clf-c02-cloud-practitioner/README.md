## How the modules map to the exam

CLF-C02 has four scored domains. Roughly:

| Exam Domain | Weight | Covered mainly in |
|---|---|---|
| Domain 1: Cloud Concepts | 24% | Modules 1, 9 |
| Domain 2: Security and Compliance | 30% | Module 4 |
| Domain 3: Cloud Technology and Services | 34% | Modules 3, 5, 6, 7, 8, 10 |
| Domain 4: Billing, Pricing, and Support | 12% | Module 2 |

This mapping is approximate — several modules touch more than one domain — but it should help you weight your study time if you're short on it before exam day.
