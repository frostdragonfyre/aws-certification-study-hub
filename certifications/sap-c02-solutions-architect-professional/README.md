# SAP-C02 — AWS Certified Solutions Architect – Professional

**Status: Complete.** All 16 modules are fully written — lecture content, slide decks, quizzes, and instructor materials. This course assumes the SAA-C03 associate-level material as a foundation and goes deeper into organizational complexity, new-solution design, continuous improvement of existing workloads, and migration and modernization — the four domains of the real SAP-C02 exam.

The course follows one evolving case study: Meridian Retail Group. Domain 1 (Modules 1–6) covers organizational complexity — multi-account strategy, governance, and cross-team requirements. Domain 2 (Modules 7–12) designs Meridian Loyalty, a new customer loyalty platform, from scratch. Domain 3 (Modules 13–14) improves Café Sol, a business Meridian acquired that's already running in AWS, using six months of real operating data. Domain 4 (Modules 15–16) migrates and modernizes Ridgeline Diner Co., a business that had never touched the cloud at all. Start at Module 1 and work down the table in order.

## How this builds on SAA-C03

If you completed [SAA-C03 Solutions Architect – Associate](../saa-c03/), this course assumes that foundation and goes deeper: multi-account governance, designing for organizations rather than single accounts, continuous improvement using real operating data instead of upfront design alone, and migrating and modernizing workloads that started outside AWS entirely. Services from SAA-C03 return here, but the questions this course asks about them are different — less "how do I use this service," more "which of several reasonable designs actually fits this organization's constraints."
