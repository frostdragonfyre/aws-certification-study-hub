# Authoring templates

[Hub home](../README.md) · [Contribution guide](../CONTRIBUTING.md)

These are starting points for authors, not finished student lessons. Replace the placeholders, keep the material original, and connect new public files to the course index.

| Template | Purpose |
| --- | --- |
| [Module](module-template.md) | A written explanation, worked scenarios, and next steps |
| [Quiz](quiz-template.md) | Public questions only |
| [Lab or activity](lab-template.md) | Learner instructions and an explicit scope |
| [Private answer-key template](quiz-answer-key-template.md) | A blank authoring template; completed keys belong in an ignored instructor-private folder |

Do not commit completed answer keys, delivery scripts, student records, or unpublished material. Run `python scripts/check_hub.py` after updating public navigation.
