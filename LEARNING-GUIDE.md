## Use the materials together

The **module** is the main written explanation. The **slide deck** provides another view of the concepts. A **quiz** asks you to practice reasoning; the public repository deliberately does not supply an answer key. Cloud Practitioner also includes ten **activities**.

Start with the course index. Its numbered table links to the material that is available. Every lesson and quiz has a course-index link so you can return without retracing folders.

Before consulting a table or glossary, try to explain the concept in your own words. Use the [scenario-question guide](shared/exam-strategy/reading-scenario-questions.md) when choosing among plausible answers.

## Understand the limits

Availability means a file exists and is linked. It does not mean every claim has been rechecked against the latest service release or exam guide. Read [EXAM-VERSIONS.md](EXAM-VERSIONS.md) and the relevant official exam guide for version changes.

The AWS Academy labs referenced in the Solutions Architect Associate material are hosted separately; they are not downloadable labs in this repository. You can read the public Markdown lessons without an AWS account. If you follow a lesson into a real AWS environment, check its permissions, resource costs, and cleanup steps before deploying anything.

Private answer keys and instructor delivery scripts are not part of the public resource. For corrections, open an issue with the learning path, module number, file link, and a description of the problem. Keep student information and private organizational data out of public issues.
